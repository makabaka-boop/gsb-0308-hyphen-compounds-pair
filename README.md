# 断字词典（Hyphenation Dictionary）

原生 TypeScript 实现的**离线断字词典页**：基于 Liang 断字算法（TeX 同源规则），
用模式 trie 对加边界符的词逐间隙计分，支持例外词表覆盖，并把每个间隙的
**最终分值、贡献该最大值的模式、被限制规则排除的原因**全部可视化。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest（含朴素逐模式扫描对拍）
npm run typecheck  # tsc --noEmit
npm run build      # 产出 dist/ 静态文件
```

### Compose（hyphen 服务）

页面为纯静态站点，由 Compose 的 `hyphen` 服务以 nginx 托管，完全离线可用：

```bash
docker compose up --build   # 打开 http://localhost:8080
```

## 规则

- **模式**（1～1000 条，每行一条）：小写 `a-z` 为主体，两端可带边界符 `.`，
  每个字符间隙（含首尾）至多一位 `0～9` 数字。例：`hy3ph`、`.ach4`、`on3.`、`1tio`。
- **匹配**：对词加边界符（`.word.`）后用模式 trie 扫描所有对齐位置；
  模式键中的 `.` 只与串两端的边界点相等，因此带点模式自然只贴在对应边界。
- **计分**：每个间隙取所有命中模式在该间隙权重的**最大值**；
  同分值并列时来源取词典中先出现的模式（trie 与朴素扫描共用同一取舍函数）。
- **可断**：间隙分值为**奇数**，且左侧 ≥ `lefthyphenmin`、右侧 ≥ `righthyphenmin`
  个字母（默认均为 2，可调 0～40）。词首/词尾边界间隙永不参与断字。
- **例外词表**：每行一词，`-` 标记显式断点。例外词**完全覆盖**模式结果：
  标记处可断（生效分值取奇数哨兵 9，仍受左右限制约束），未标记处一律禁止；
  不带 `-` 的例外词即"禁止一切断字"。同词重复时后者覆盖前者。
- **输入词**：空白分隔，≤2000 词，每词 1～40 个小写字母；非法/超长/超量条目
  跳过并在页面上给出提示。

复合词可以用一个或多个词段间的连接号输入，例如 `hyphenation-dictionary`。连接号是原词的一部分，结果中始终保留；模式、左右保留字母数与例外词按各词段独立判定，词段边缘不可再断。例外词表用 `=` 表示复合词的固定连接号、`-` 表示可断间隙：`hy-phen=ation` 对应输入 `hyphen-ation`。若整条复合词有例外条目，它覆盖各词段自己的例外和模式；否则各词段独立使用自己的例外条目与模式。页面筹码、间隙明细和导出 JSON 的位置沿原输入串统一编号，连接号邻近的间隙应清楚标识为固定边界；额外插入的断字连字符只来自可断间隙。字母总数上限仍为 40，连续、首尾连接号不是合法词条。

## 页面

- 每个词渲染为「字母 + 间隙筹码」序列，筹码显示该间隙**最终分值**并按状态着色
  （可断 / 例外断点 / 奇数但被限制排除 / 偶数或无命中 / 例外禁止 / 词边界）。
- 点击任意间隙展开**逐间隙明细表**：左/右字母数、模式分值、贡献最大值的模式、
  最终分值、状态与原因。
- 修改模式、例外、词表或限制参数后 150ms 内自动重新计算。
- **导出 JSON**：与页面高亮使用同一份计算结果（`breakPoints`、逐间隙
  `breakable`、`hyphenated` 三者必然一致），并附带模式与例外词典以便复现。

## 测试

`test/` 下五个套件共 52 例：

- `pattern.test.ts`：模式语法（边界符位置、间隙数字唯一性、数量上限、去重）。
- `trie.test.ts`：**trie 与朴素逐模式扫描对拍**——固定用例（重叠规则取最大值、
  同分值来源取舍、边界匹配、首间隙数字映射）+ 300 随机模式 × 300 随机词逐位一致。
- `analyze.test.ts`：The TeXbook 附录 H 经典例（`hyphenation` → `hy-phen-a-tion`）、
  边界间隙不可断、左右最少保留字母数、例外覆盖（禁止/新增/受限制约束）、无断点词。
- `compound.test.ts`：复合词词段独立计分（边界模式在词段边缘匹配、左右保留按词段判定）、
  连接号固定边界间隙（逐间隙与导出 JSON 均可辨识）、`=` 固定连接号例外（整条覆盖各词段、
  词段级例外独立生效、断点受词段左右限制）、例外解析（`=`/`-` 归一、连续连接号拒绝）。
- `io.test.ts`：输入解析限制，以及**导出 JSON 与高亮一致性**不变量
  （`breakPoints` ⇔ 逐间隙 `breakable` ⇔ `hyphenated`）。

## 目录

```
src/
  pattern.ts   模式解析与校验
  trie.ts      模式 trie（分值存于 key 终端节点，仅完整命中计分）
  naive.ts     朴素逐模式扫描（对拍参考实现）
  analyze.ts   Hyphenator：复合词按词段切分 → 计分 → 例外覆盖 → 左右限制 → 逐间隙结论
  io.ts        输入解析、限制参数、导出 JSON
  app.ts       页面渲染与交互（无框架）
  defaults.ts  默认示例词典（plain TeX 美式英语模式节选 + 例外）
test/          Vitest 套件
Dockerfile     多阶段构建（node 构建 → nginx 托管）
compose.yaml   hyphen 服务（8080:80）
```
